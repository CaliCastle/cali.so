## Confirmed architecture decisions

- The supported template is public-first with an optional full Operator Stack.
- All non-secret fork identity lives in one committed, typed
  `site.config.ts`. Secrets and environment-specific provider settings remain
  in environment variables.
- Personal posts, photographs, projects, and branding stay in the main
  repository as the working example. Fork documentation marks their
  replacement as mandatory; there is no second template branch.
- `operatorStack: false` makes operator and operator-published routes return
  404 and prevents provider/environment initialization. It does not physically
  delete their source or packages from a clone that can also set the profile to
  `true`.
- The old bilingual v2 cloning article is rewritten as a concise v3 overview
  pointing to one canonical `docs/forking.md`.
- Fork setup has a read-only checker. There is no mutating initializer or
  generator.
- v3 has no icon-library abstraction. Existing hand-picked direct imports stay
  as chosen. The dormant icon and radius switchers are removed without a
  visible design change.

## Findings considered and rejected

- Delete `content/legacy-url-manifest.json`, redirects, rewrites, retired
  confirmation routes, archived newsletters, or historical post assets:
  rejected because they are active URL/publication contracts, not dead source.
- Rewrite or delete applied database migrations and snapshots: rejected because
  they are immutable deployment history.
- Drop legacy production tables in this bundle: deferred to a separately
  approved contract-migration effort with archival proof and the required
  production confirmations.
- Ship a separate template branch: rejected because it would drift from the
  personal site that is meant to remain the working example.
- Add a destructive fork initializer: rejected because the safe supported path
  is explicit configuration, documentation, and read-only verification.
- Support arbitrary locale sets in this cleanup: rejected as scope expansion.
  The current paired Chinese/English route contract remains the supported v3
  template contract.
- Physically tree-shake the Operator Stack packages from public-only clones:
  rejected without a separate distribution/build system. The selected profile
  removes reachability and infrastructure requirements, not source ownership.
